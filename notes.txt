Toda classe em Java precisa estar dentro de um pacote.
Por exemplo a classe TodolistApplication está dentro do pacote br.com.matheusmosso.todolist
Isso serve para toda clase. Linha original sendo package br.com.matheusmosso.todolist;

Controller é quem recebe a requisição do usuário, ela faria a conexão entre a requisição do usuário as demais rotas, ex database
Controller precisa estar dentro da estrutura da main, pois o Spring irá verificar na main se há outras pastas como Controller, Services e repositories, por conta disso é necessário
que essas pastas estejam dentro da pasta que está o main, nesse projeto seria a todolist

Rest é um estilo de arquitetura, conjunto de restrições que padronizam a comunicação na web afim de ser leve e escalável


Get e set: 

Get é utilizado quando se deseja recuperar uma informação apontando para um atributo

Set é utilizado para atualizar ou inserir informações para um atributo em específico

Para não ser necessário ficar criando todos os Get e Set dos atributos que desejamos, foi utilizado o Lombok que seria um lib do java que já realizaria esses Get e Set.
Utilizando o @Data no model, ele já realizaria para os atributos que possui no mesmo, caso fosse desejado apenas os Gets seria @Get ou set @Set.

Spring Data JPA - ORM responsável por fazer o sistema se comunicar com o banco de dados, basicamente converte a linguagem para uma linguagem que o DB entenda.

H2 DataBase, banco utilizado, banco com base em memória, caso a aplicação seja reiniciada os dados serão perdidos.

pom.xml - Coloco possíveis dependências que a aplicação necessite para agilizar trabalhos. Ex: Dependeby bcript para criptografia de senha

No FilterTask ele recebe alguns parametros como o request, response e chain, o request sendo a requisição do usuário, o response é o que é retornado ao usuário 
Ex: uma mensagem de token inválido caso a senha esteja incorreta ou usuário, e o chain seria o que daria sequencia para outras rotas (para controller nesse caso),
isso ocorre apenas se a requisição passar pela autenticação anterior.

A seguir, possível filtro que pode ser utilizado (ServLet):

//Filtro para realizar a autenticação de usuário, sendo verificado se o username e a senha estão corretos e cadastrados no DB, caso estejam a tarefa do usuário é cadastrado
@Component //Anotação necessária para que o springBoot gerencie essa classe
public class FilterTaskAuth implements Filter {

    @Override
    public void doFilter(ServletRequest request, ServletResponse response, FilterChain chain)
            throws IOException, ServletException {
        
            //Executar alguma ação
            System.out.println("Chegou no filtro");
            chain.doFilter(request, response);
    }
    
}

*Obs: Esse filtro pode ser utiizado na aplicação porém utiliza parâmetros do tipo Servlet e não HttpServlet, por se tratar de uma api via HHTP e Rest é melhor utilizar o filtro que
possui no springBoot pois não é necessário realizar a conversão para o HttpServlet.
